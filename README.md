# AI CodeOps demo: cart

A tiny, dependency-free shopping-cart module used in the [AI CodeOps](https://aicodeops.dev) tutorial videos.

AI agents in AI CodeOps plan, build, review and test changes to this repo, and nothing merges until the tests pass on that exact version, the AI review is clear and a person approves it.

## Run the tests

```bash
npm test
```

Requires Node.js 18 or later. No dependencies to install.
